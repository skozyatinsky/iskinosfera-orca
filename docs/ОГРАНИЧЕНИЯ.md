# ОГРАНИЧЕНИЯ.md — iskinosfera-orca

Документ фиксирует осознанные ограничения форка десктопного клиента Искиносферы:

1. **Базовая кодовая база:**
   - Форк проекта `stablyai/orca`. Ключевые изменения должны учитывать обратную совместимость с апстримом.

2. **Кроссплатформенность:**
   - Поддерживаются macOS, Linux (Ubuntu 20.04+ floor), Windows. Нативные модули требуют строгой проверки ABI.

3. **Стандарт парка:**
   - Подключение стандарта осуществляется в режиме `tool_pinned` без ломки структуры апстрима `docs/`.
